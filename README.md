# Customer Accounts Microservice

[![CI Build](https://github.com/Shantanu2806/Coursera/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/Shantanu2806/Coursera/actions/workflows/ci-build.yaml)

A RESTful Customer Accounts microservice developed using Python Flask, SQLAlchemy, Docker, Kubernetes, and Tekton CI/CD pipelines.

## Project Overview
This microservice provides complete CRUD operations for managing customer accounts with:
- Agile planning via GitHub Projects Kanban board
- Automated testing with Nosetests and code quality checks with Flake8
- Continuous Integration automation with GitHub Actions
- Security enforcement using Flask-Talisman security headers and Flask-CORS
- Containerization using Docker
- Orchestration and deployment to Kubernetes
- Automated continuous delivery pipeline using Tekton
