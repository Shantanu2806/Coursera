# CI/CD Final Project

## Project Overview
This project implements a complete CI/CD pipeline using **GitHub Actions** for automated continuous integration (linting with `flake8` and unit testing with `nose`) and **Tekton** with **OpenShift Pipelines** for automated continuous deployment.

### Technologies Used
- **Python 3.9** / Flask
- **GitHub Actions** (CI Workflow)
- **Flake8** (Code linting and quality checks)
- **Nose / nosetests** (Automated unit testing)
- **Tekton Pipelines** (Cloud-native CI/CD tasks)
- **Red Hat OpenShift** (Container deployment & persistent storage)
